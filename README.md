# Crux

Spaced repetition for algorithm interview patterns. It trains recognition, not recall.

**[Download for macOS](https://gauthierpiarrette.github.io/crux-app/)** · macOS 13+ · Apple silicon · free

Memory state attaches to a *pattern* and one facet of it — its trigger, its invariant,
its nearest wrong answer — and the problem you are shown is drawn fresh every time, so
there is no puzzle to memorise.

Your review history stays on your Mac. No account, no server, no analytics.

This repository hosts the landing page and the signed release. The application source
is not public.
